## Кнопка «Сменить услугу» в карточке записи

**Статус:** не сделано — нужен только UI, бэкенд готов
**Заведено:** 2026-10-19, по просьбе Ани

### Зачем

Клиент записался на одну услугу, внёс предоплату, пришёл — и уже на месте решил взять
другую. Сейчас Аня вынуждена отменять запись, возвращать деньги, заводить новую запись и
снова брать предоплату. Нужно, чтобы предоплата просто переносилась на новую услугу.

### Что уже есть

Всё, кроме кнопки:

- `POST /api/v1/bookings/<id>/edit-services/` → `BookingEditServicesView`
  (`mobile_api/views.py:1817`) → `change_booking_service()` (`bookings/client_actions.py`).
  Меняет услугу прямо в записи, пересчитывает длительность, зону и снимки цены,
  проверяет занятость слота. Предоплата остаётся привязанной к той же записи и
  засчитывается в новую цену — возвращать и брать заново ничего не надо.
- Ответ содержит `extra_due` (сколько ещё доплатить), `manual_refund_required`
  (новая услуга дешевле — разницу вернуть вручную) и, если доплата нужна,
  `payment_id` + `checkout_url` на готовую Stripe-сессию.
- Метод клиента уже написан: `AnnaApi.editBookingService(bookingId, payload)`
  (`lib/api/anna_api.dart:497`). **Его сейчас не вызывает ни один экран** — поэтому
  функции как будто нет.
- Покрыто тестом на бэкенде: `bookings.tests` →
  `test_adding_higher_price_service_creates_extra_payment` (оплачено 50 €,
  перешли на услугу дороже → к доплате ровно 30 €).

### Что сделать

В `lib/screens/calendar_screen.dart`, в нижнем листе с деталями записи — там же, где
сейчас «Reprogramar» и «Editar» (искать по `t.tr('Reprogramar')`):

1. Добавить кнопку «Cambiar servicio» / «Сменить услугу».
2. По нажатию — список услуг этого мастера (`refs.servicesForEmployee(employee)`,
   тот же, что в форме редактирования) и `editBookingService(id, {'service': <id>})`.
3. Разобрать ответ:
   - `extra_due > 0` и есть `checkout_url` → показать сумму доплаты и открыть ссылку
     (или отправить клиенту), как это уже делается для обычной оплаты;
   - `manual_refund_required == true` → предупредить, что новая услуга дешевле и
     разницу надо вернуть вручную;
   - иначе — просто «услуга изменена, предоплата перенесена».
4. Обновить карточку записи из `payload['booking']` — это уже обычный booking-объект.

### Проверка

Взять запись с оплаченной предоплатой, сменить услугу на более дорогую — запись должна
остаться той же (тот же id), предоплата остаться на месте, а к доплате прийти только
разница. Отмены и возврата быть не должно.
